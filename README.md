### About

Software Engineer at **[Intelligent Entertainment](https://iegroup.gr/)**, working across the software stack of interactive attractions. I build Python game controllers, ESP32 firmware, Java backends and React frontends for escape rooms and arcade gaming platforms running in 10+ countries — from the sensors on the wall to the services and screens that drive them.

- 🔹 Building interactive experiences for [TheMindtrap](https://themindtrap.gr/?lang=el) & [Agent Factory](https://agent-factory.com/)
- 🔹 Python (asyncio, MQTT, WebSocket) game controllers and shared gameplay libraries
- 🔹 C++ firmware on ESP32 networks — RFID, LIDAR, sensors, locks, motors, LED strips
- 🔹 Java / Spring Boot backends and React + TypeScript frontends
- 🔹 Supporting international venues across Europe, the US, Australia and the Middle East

### Projects

**[Guitar Companion](https://github.com/kwanto619/PlayGuitarApp)** · [live](https://play-guitar-app.vercel.app)
Full-stack guitar app — chromatic tuner with Web Audio pitch detection, metronome, 120+ chord library, song import & transpose, PDF music-book reader and user profiles. *Next.js · React · TypeScript · Supabase*

**Interactive Escape** — diploma thesis
Hybrid escape room where real sensors drive a Roblox game: ESP32 firmware, a Python serial bridge and a Node.js / Express API. *C++ · Python · Node.js · Luau*

**[Volunteer Team of Pylaia-Chortiatis](https://ethelontiki-omada-filyrou.vercel.app)**
Bilingual site for a civil-protection volunteer team — live wildfire map (NASA FIRMS), earthquake feed, member news publishing and admin area. *React · Leaflet · Supabase*

**[Home Butler](https://home-butler-two.vercel.app)**
Household organiser (PWA) — groceries with cost history, monthly bills, expense charts and daily email reminders. *Next.js · TypeScript · Supabase*
